# Assets

Place static assets here. They will be processed by Vite and content-hashed at build time.

## Subdirectories

| Directory    | Contents                                    |
|--------------|---------------------------------------------|
| `images/`    | JPEG / PNG / WebP photographs and graphics  |
| `icons/`     | SVG icons not covered by Lucide React       |
| `fonts/`     | Self-hosted web fonts (if not using Google) |
| `models/`    | Three.js `.glb` / `.gltf` 3D model files   |

## Import

```tsx
import robotImage from '@/assets/images/robot-hero.webp';
```
